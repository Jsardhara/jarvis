# Deep Test + Redundancy Pass — 2026-05-13

## Bug fix (B1): agent-page navigation lock

**Root cause:** `web/src/hooks/useAgentChat.ts` opened an `EventSource` on every chat `send()` but never closed it on unmount. Each visit to an Atlas agent page that sent at least one message leaked a connection. Chrome/Firefox cap concurrent HTTP/1.1 connections per origin at 6 — once 6 SSE streams were pinned open against `localhost:8765`, every subsequent fetch (Next.js route prefetch + RSC fetches + `/api/sidebar` polls + WebSocket upgrades) queued indefinitely behind the saturated pool. Sidebar clicks appeared dead because the navigation kicked off but the route never loaded.

**Fix:** Added a mount-scoped `useEffect` cleanup that closes `esRef.current` on unmount (`useAgentChat.ts:85-90`). 11 lines.

**Verify:** Visit `/atlas/agents/oracle`, send a chat message, click any sidebar link. Navigation now works.
